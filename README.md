## ✨ 功能

### 刷题库（260 题）
- **题型**：单选 55 / 多选 30 / 判断 40 / 填空 20 / **案例 28** / 简答 26 / 名词解释 26 / **2026 换版 35**
- 全部附**解析 + 标准条款出处**
- 按题型 / 按章节（第 4~10 章）练习，随机打乱，题量可选
- **案例专题**：给审核情景，判断是否符合、违反哪一条款（内审员核心能力）
- **模拟考**：随机组卷 20/30/50 题，限时，交卷统一评分（不含主观题）；**交卷后逐题给出正确答案、解析与依据条款**，可“只看错题”，可打印/导出
- **错题本 / 收藏夹**，学习统计（各题型、各章节正确率）
- **错题精练**：只考错题、循环到清零（答对一题自动移出错题本），带轮次进度
- **导出错题集**：打印/存 PDF、导出 Markdown / TXT，可选是否含答案解析
- 简答题与名词解释为**自评模式**：先自答 → 看参考答案与要点 → 自评掌握程度
- 进度用 localStorage 保存在本机；键盘 `1-5`/`A-E` 选项、`← →` 翻页

### 工作台
- **入门路线**：0 基础 → 能独立做内审的 4 周计划
- **条款速查**：标准 4~10 章 43 条**详解**（要义 / 目的 / 检查问题 / 常见客观证据 / 常见不符合 / 关联条款），点条款跳转详情页（可翻页、可打印），支持全文搜索
- **内审检查表生成器**：选部门 + 勾条款 → 生成表格 → 打印/存 PDF
- **岗位定制检查表**：采购 / 生产 / 质检 / 仓储 / 销售 / 设计 / 人事 / 管理层，8 套；每套含岗位职责要点、检查项目、该岗位最容易被开的 5 个不符合（可点条款跳详情）
- **不符合项报告（NCR）**：按标准写法填写 → 打印 / 导出，含示例
- **术语 / 模板**：26 条中英术语 + 不符合项描述万能模板 + 分级参考
- **模拟内审**：首次会 / 现场取证技巧 / 末次会 的议程与话术
- **2026 换版**：ISO 9001:2026 时间线与主要变化（附来源与免责说明）
- **差异对照**：2015 → 2026 条款级对照表 + 5 个变化关键词 + 过渡时间线
- **内审报告**：按报告标准结构填写，打印/存 PDF 或导出；附“内审报告怎么写”教材说明
- **对策库**：27 条高频不符合的 典型描述 / 常见原因 / 纠正措施范例 / 举一反三，可搜索、可导出
- **审核文档**：内审计划、首次会议记录、末次会议记录三份文书，可填可印，附写法教材
- **审核思路**：从线索到结论的 5 步思路图 + 20 条按条款的追查链（线索 → 追问 → 取证 → 判定）

## 🚀 使用

### 本地
直接双击 `iso9001-quiz.html` 或 `iso9001-workbench.html` 即可（无需联网、无需安装）。

### 手机上使用（重点）

页面已针对手机优化，两种用法：

1. **在线（推荐、便于分享）**：部署到 GitHub Pages 后，用手机浏览器打开 `https://nanye1686.github.io/iso9001-study/`，即可刷题、查条款、生成检查表；可把链接分享给别人。
2. **添加到主屏幕（像 App）**：手机的 Chrome / Edge / Safari 打开后再选「添加到主屏幕 / 添加到桌面」，之后一键全屏打开，**断网也能用**（单文件离线）。
3. **本地/离线**：把 `iso9001-quiz.html` 或 `iso9001-workbench.html` 直接拷到手机再用浏览器打开（微信里传文件也行）。

### 部署为在线网页（GitHub Pages，免费）
1. 把本仓库推到 GitHub
2. 仓库 **Settings → Pages → Source** 选择 **Deploy from a branch** → `main` → `/(root)`
3. 访问 `https://nanye1686.github.io/iso9001-study/`
（`index.html` 是落地页，会自动链接两个工具；`.nojekyll` 已就位，无需额外配置）

## 🛠 修改题目

题库与界面分离，题目是纯 JS 数据：

```
src/
  bank-single.js   单选题
  bank-multi.js    多选题
  bank-judge.js    判断题
  bank-blank.js    填空题
  bank-case.js     案例题
  bank-short.js    简答题
  bank-term.js     名词解释
  bank-v2026.js    2026 换版专题（混合题型）
  app-template.html  界面与逻辑（含 /*__BANK_DATA__*/ 占位）
  build.js           构建脚本
```

改完题目后，在仓库根目录执行：

```bash
node src/build.js
```

会重新生成 `iso9001-quiz.html`（并校验题量与 ID 唯一性）。

**题目字段说明**（以单选为例）：

```js
{id:'S001', ch:'4', topic:'组织环境', lv:1,
 stem:'题干……', options:['A','B','C','D'], answer:[2],
 explain:'解析……', ref:'4.1'}
```

- `type` 由所在文件决定；`ch` 为章节（`0`=基础概念，`4`~`10` 对应标准章节）
- 填空：`answers:['答案']`（同空多答案用 `|` 分隔）
- 简答 / 名词解释：`model`（参考答案）、`key`（要点数组）
- 判断题无需写 `options`，构建时会自动补 `['正确','错误']`
